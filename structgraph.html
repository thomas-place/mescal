Detailed Description

Type used to represent a directed unlabeled graph.

Remarks
For each vertex q, the vertices that are connected to q by an edge are stored in the array storage between the indices intervals[q] (included) and intervals[q+1] (excluded). This list must be sorted in increasing order.
