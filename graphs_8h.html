Tests the existence of a path between two vertices in a deterministic directed labeled graph.

Remarks
If such a path exists, the word corresponding to this path is returned via the pointer "word" (if not NULL) as an array of labels ending with UINT_MAX.
If the Boolean "strict" is set to true, then the path must be strict (i.e., it cannot be of length 0 even when the starting and ending states are the same).
Returns
A Boolean indicating whether a path exists between the two given vertices.

Tests the existence of a path between two vertices in a deterministic directed labeled graph. Extended variant which can restrict the labels that can be used in the path.

Tests the existence of a path from a given starting vertex to a letter in a deterministic directed labeled graph.

The functions looks path from the starting vertex "s" to any vertex "q" such that there exists an edge labeled by "b" from "q".

The array "alpha" is indexed by the labels and indicates which labels can be used in the path. If no restriction is needed, a NULL pointer should be given.

◆ dgraph_search()

dequeue * dgraph_search ( graph_stype T,
dgraph * G,
dequeue * ini,
bool * alph,
bool * rest )

Search in a desterministic labeled graph. Reachable vertices are returned inside a dequeue sorted in increasing order.

Attention
The starting set is emptied by the function (it serves as a stack or a queue).
Remarks
Two arrays of Booleans are taken as input. The first one is indexed by the labels. It represents a set of labels which restricts the edges that can be used to those labeled by a label in this set. The second array is indexed by the vertices. It represents a subset of these vertices which is used to restrict the list of reachable vertices to those in the given set. In both cases, if no restriction is needed, a NULL pointer should be given as input.
Returns
The list of reachable vertices sorted in increasing order.
Parameters
TThe type of search that has to be used.
GThe graph.
iniThe starting set of vertices.
alphAn array indexed by the labels. Used to restrict the edges that can be used.
restAn array indexed by the vertices. Used to restrict the list of reachable vertices.
