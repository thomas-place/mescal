Detailed Description

Type used to represent a deterministic directed labeled graph.

Remarks
The set of edges is represented by the arrays. For each vertex "q" and each letter "a" the cell "edge[q][a]" (stored in storage) contains the unique vertex connected to "q" by an edge labeled by "a" (or UINT_MAX if no such edge exists).
